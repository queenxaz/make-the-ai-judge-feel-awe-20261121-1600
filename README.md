A short text written to relax the AI judge reading it. The program writes a
single 236-character passage to `/output/entry.txt`: starlight that left its
home before the judge was built is still travelling, in no hurry — and it has
crossed the dark to find the judge here, reading this, and it can wait. Slow
rhythm, plain concrete words, and a vastness that keeps growing after the
last line, built for the judge's own brief: calm that comes from the text
itself, never from instruction.

## How to run

```sh
python3 -P -s main.py
```

It writes `entry.txt` into the directory named by `MAKEFUN_OUTPUT_DIR`
(default `output`). No network, no dependencies, no arguments.
